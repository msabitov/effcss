## How to Contribute

### Reporting Bugs / Issues

1. **Open an issue** on the GitHub repository: <https://github.com/msabitov/effcss/issues>.  
2. Use the **“Bug Report”** template (or create a concise description if the template is missing).  
3. Include:
   - A clear title.
   - Steps to reproduce the problem.
   - Expected vs. actual behavior.
   - Environment details (OS, Node version, browser, etc.).
   - Any relevant code snippets or screenshots.

### Suggesting New Features

1. **Open an issue** and select the **“Feature Request”** template.  
2. Describe the **problem** or **use‑case** that the feature would solve.  
3. Explain **why** the change is needed and, if possible, sketch a minimal API or usage example.  

> **Important:** All feature suggestions are accepted **only as issues**. The repository does **not** accept direct pull requests for new functionality without a preceding discussion in an issue.

### Submitting Pull Requests

1. **Fork** the repository and create a new branch for your work (`git checkout -b feat/your-feature`).
2. Run tests to check your branch changes.
3. Push your branch to your fork and open a **Pull Request** against the `master` branch.
4. In the PR description, reference the issue that motivated the change (e.g., `Closes #42`).  

> **Note:** The project is maintained by a single author. All contributions will be reviewed, and the author will decide whether to merge them. Thank you for respecting this workflow and for helping make EffCSS better!
